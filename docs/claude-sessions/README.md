# Claude Code session logs

One file per Claude Code session that changed this repo, newest first. Each log records the
prompt, the decisions taken and why, what was verified (with the actual commands and results),
and what was left unverified. The point is auditability: a reader should be able to see how the
codebase was produced and where a human should look twice.
